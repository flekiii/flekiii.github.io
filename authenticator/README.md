# Fleki Authenticator

A free, standalone, privacy-focused progressive web app hosted at:

**https://fleki-authenticator.flekideveloper.workers.dev/**

This app is independent of Fleki's Wrld login and lives at a **different origin**. The source is in this folder; the deployed Cloudflare Worker serves the seven static assets (no backend or external scripts).

## Features
- RFC 6238 TOTP (SHA-1), standard 6-digit codes and supported 8-digit codes.
- Add any compatible account by pasting its Base32 setup key or a `otpauth://totp/...` link.
- Offline QR code scanning via native BarcodeDetector where the browser supports it; otherwise manual entry.
- Vault encrypted on-device with AES-256-GCM and a 360,000-iteration PBKDF2-SHA-256 derived key.
- Secrets are not transmitted to the server; all cryptography is handled by Web Crypto.
- Vault automatically locks after 5 minutes without interaction and wipes rendered OTP codes.
- Export and import **encrypted** JSON backups, protected by the original vault password.
- Offline support through a static-only service worker; install as a PWA on supported browsers.

## Use with Fleki's Wrld
1. Open Fleki's Wrld -> Profile -> 2FA.
2. Select authenticator enrollment to display your personal setup key.
3. On a **separate device (preferably your phone)** open Fleki Authenticator, create a vault password, and add the Fleki's Wrld setup key.
4. Type the generated six-digit code into Fleki's Wrld to finish enabling 2FA.
5. Save the **Fleki's Wrld recovery codes** and an **encrypted Fleki Authenticator backup** in different, safe locations.

## Security limitations
- A software authenticator installed on the same device as the login session is less independent than a different trusted device.
- The vault password cannot be reset. Losing the password and backup may permanently lose TOTP secrets.
- Local storage is erased if the browser clears site data. Keep encrypted backups.
- The app does not currently support hardware FIDO2/WebAuthn security keys.
- The QR reader depends on BarcodeDetector; Firefox may require manual-key entry.
- The first visit needs internet to cache static app files. Offline operation works after successful caching.
- Browser extensions and devices compromised with malware can still undermine local secret confidentiality.
- **Do not enter a secret generated by an unknown service.** Confirm the issuer and account name before saving.
