UNINSTALL

How to remove Fleki Power Menu.

Choose the method you used to run the app. These commands only target Fleki Power Menu, not Fleki Orbit or your XFCE panel.

AppImage: delete the downloaded file from its folder. If you put it in Downloads:
rm -i -- "$HOME/Downloads/Fleki-Power-Menu-0.2.0-x86_64.AppImage"
If you installed the earlier Python version with autostart, run:
pkill -f "^python3 $HOME/.local/bin/fleki-power-menu.py$" || true
rm -i -- "$HOME/.local/bin/fleki-power-menu.py"
find "$HOME/.config/autostart" -maxdepth 1 -type f -iname '*fleki*power*.desktop' -print

Review the displayed autostart file paths and remove only the Fleki Power Menu entry if present. Do not delete other desktop entries.

Optional: to also erase your saved menu color, run:

rm -i -- "$HOME/.config/fleki-power-menu/settings.json"
