Getting started

  1. Sign in with XONI Mail. Add Lipssi to your library and choose your language and theme in Settings.
  2. Lipssi has not been released. Pre-download waits for a verified release and works while VELTRIX is open.
  3. You choose the game folder and allow automatic downloads. You can pause, resume or cancel them in Downloads.
  4. Purchases and payments are not available. L-lipsix packs show concept prices only.

Privacy & data

Login tokens are stored in the system keyring. Settings, local profiles and notification history are stored on this device.

VELTRIX sends account requests to its server and confirmation messages through XONI Mail. Communities are public.

Exchange rates use an external provider. Bug reports open GitHub in your browser; nothing is sent automatically.

A previous valid settings snapshot is kept locally before saving changes. Updates back up source files and roll back if checks fail.

Help & support

For security concerns, contact the developer privately. Never post passwords, login codes or tokens in a public report.
